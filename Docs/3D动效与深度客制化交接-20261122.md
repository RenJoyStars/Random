## 二、3D 立体动效体系（`Random/ToolFlourish.swift`）

所有 3D 透视均由 `model.motion3D` 统一受控（默认开启，老旧教室设备可在设置中一键退回轻快 2D）：

1. **3D 机械滚筒文字（`SlotRoller`）**：叠加 X 轴 `rotation3DEffect(±34°, perspective: 0.55)`，点名姓名、随机数字、随机字母、HEX 色值滚动时呈现立体翻页滚筒景深感。
2. **3D 金属硬币（`CoinStage`）**：
   - 保留无镜像的 `cos(θ)` 正反切换机制（汉字绝不镜像反写），叠加 **4 层错位 3D 金属侧边厚度**、抛起 X 轴倾角透视、动态缩小的桌面投影与扫光镜面反射。
   - 支持 **3 种金属材质**（经典银币 / 鎏金纪念币 / 暖铜复古币）及 **自定义双面文字**（自动缩放适配 1–3 字，如「唱/奏」「男/女」）。
3. **3D 立体翻滚骰子（`DiceStage` + `DieFace`）**：
   - 滚动时每颗骰子错相沿 X/Y/Z 三轴 3D 翻滚并伴随垂直抛跳，下方同步渲染实时缩放的桌面椭圆投影；落桌时带 3D 前倾回弹。
   - `DieFace` 升级为 **3D 倒角实体骰面**（高光斜边 + 立体阴影 + 1 点红心经典配色），支持 **象牙白 / 曜石黑 / 翡翠绿 / 宝石红** 4 套材质皮肤。
4. **3D 弧形扇面抽卡与无镜像翻牌（`CardStage` + `FlippingCard` + `CardBack`）**：
   - 洗牌时牌背呈微弧形扇面错落起伏并带 Y 轴透视摇曳；
   - 落定揭晓采用 **真 Y 轴 3D 翻转（0°→90° 背面隐去 → 换正面 → -90°→0° 展平，绝不镜像）** + 浮空抬升；落定后悬停任意一张牌自动拉直、抬起并置顶放大；
   - `CardBack` 支持 **经典蓝 / 皇家红 / 祖母绿 / 暗夜金** 4 套斜纹双线框牌背。
5. **3D 猜拳 / 色卡 / 分组 / 是或否**：
   - `RPSStage`：蓄力时两只手带 X 轴俯仰透视，获胜方卡片亮绿色胜利光环；
   - `ColorStage`：色块悬停 3D 微倾 + 玻璃斜切高光，落定双层同色光环扩散；
   - `GroupShuffleStage`：洗牌叠牌带 X 轴桌面俯视倾角；
   - `YesNoStage`：滚动时沿 Y/Z 轴做 3D 天平摇摆，支持自定义正反文案自动缩放。

## 三、全工具音效/特效整合与深度客制化

- **全工具特效覆盖**：为骰子、硬币、抽卡、颜色、猜拳（获胜时）全部接入 `celebrationOverlay` 与 `cheer()`，并由设置项「全工具落定特效」统一开关。
- **音效策略自由切换**：设置项「实物工具优先拟物声」默认开启（保持骰子/硬币/牌的真实物理声）；关闭后全部 12 工具统一共享 25 种庆典落定音。
- **深度客制化矩阵（全部持久化）**：
  - 全局外观：6 档舞台主题色（跟随系统 / 学院蓝 / 琥珀金 / 翡翠绿 / 绯红 / 紫罗兰）+ 3D 立体动效开关；
  - 硬币：3 种金属材质 + 正反面自定义文字；
  - 骰子：4 种立体材质皮肤；
  - 抽卡：4 种牌背风格；
  - 抽小组/声部：新增第 4 模式「自定义」（逗号/顿号/换行分隔，如 `弦乐组, 管乐组, 打击乐组`）；
  - 是或否：正反面自定义文案（如 `加练 / 下课`）；
  - 倒计时：最后 3 秒倒数提示音开关。
