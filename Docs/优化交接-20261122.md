## 二、代码架构与底层健壮性升级

### 1. 音频引擎真正按需懒加载（`Random/Sound.swift`）
- **原隐患**：`Sound.volume` 的 `didSet` 无条件调用 `Sound.shared.applyVolume()`，而 `Sound.init()` 直接创建 `AVAudioEngine()` 与 `AVAudioMixerNode()`。在 `AppModel.load()` 恢复音量配置时，即便 `soundOn == false` 或处于无音频设备/无头环境，也会提前初始化 CoreAudio 并触发 `AVAudioMixerNode` 异常崩溃。
- **修复**：
  - 将 `engine`、`mixer` 改为可选属性，引入 `private static var isAudioGraphReady = false`。
  - 音频图搭建、12 个 `AVAudioPlayerNode` 挂接、CoreAudio 默认输出设备监听与 `AVAudioEngineConfigurationChange` 监听全部移入 `ensureAudioGraph()`，仅在 `start()` 真正准备发声时执行一次。
  - `Sound.volume.didSet` 仅在 `isAudioGraphReady == true` 时同步 `mixer?.outputVolume`。

### 2. 状态安全、完整持久化与课堂动作扩展（`Random/AppModel.swift`）
- **切页/换班中止滚动（`cancelActiveRoll()`）**：
  - 在 `selection.didSet` 与 `switchClass(_:)` 中调用 `cancelActiveRoll()`，立即销毁滚动 `timer`、取消延迟朗读 `speechWorkItem`、归零全部 12 个 `*Rolling` 状态位；同时在 `drawPick()` / `drawSequence()` 的 `settle` 闭包中捕获 `targetClassID` 二次校验，根治「滚动中途切班导致结果写脏新班级」的并发隐患。
- **补齐偏好设置自动持久化**：
  - 为原先缺少 `didSet { persist() }` 的 20 项属性（`padZero`、`noRepeat`、`fairPick`、`showStudentNumber`、`pickCount`、`numMin`、`numMax`、`numCount`、`numUnique`、`numNoRepeat`、`diceCount`、`diceFaces`、`includeJokers`、`cardDrawCount`、`paletteMode`、`letterScope`、`letterUppercase`、`groupPickTotal`、`groupPickCount`、`groupPickMode`）补齐自动持久化，确保修改设置后直接退出不丢状态。
- **新增课堂高频能力**：
  - `fairPickBadge(for:) -> String?`：开启公平点名且落定后，返回「公平加权 · 本学期首次 / 第 N 次」等透明说明。
  - `skipAndRedraw()`：一键撤销刚刚点中的同学（同步回滚已抽池与历史统计）并立刻补抽，适配学生请假/缺勤场景。
  - `extendCountdown(by:)`：在不打断当前倒计时的前提下追加秒数，并按需扩展 `countdownTotal` 保证进度条比例平滑。
- **历史时间线补全**：
  - `drawSequence()` 写入历史时补传 `classID: targetClassID`，支持历史页按班级筛选。
  - `drawGroupPick()` 落定后补写 `logHistory(kind: Tool.groupPick.rawValue, classID: self.classID, text: ...)`。
- **资源清理**：`deinit` 统一清理 `timer`、`countdownTimer`、`speechWorkItem` 与 `persistWorkItem`。

### 3. 生命周期与工程卫生（`ToolFlourish.swift` / `Tests/main.swift` / `Tools/make_xcodeproj.py`）
- `FlippingCard` 改用 `@State private var flipTask: Task<Void, Never>?`，在 `.onDisappear` 取消，避免切页后写已销毁视图状态。
- 修复 `Tests/main.swift:292` `CelebrationTheme.resolve(...) != nil` 编译警告。
- 修复 `Tools/make_xcodeproj.py` 中遗留的 `GlassKit.swift` 并补入 `ToolFlourish.swift`，防止后续重生成工程时报错。

## 三、界面视觉与课堂交互升级

### 1. 设计系统（`Random/DesignKit.swift`）
- **原生材质层级**：严守工程红线（不使用 `glassEffect`、不引入半点字号），为 `StageCard`、`CardGroup` 和独立 `Bar` 增加深浅色自适应阴影与「顶部高光 → 底部 `separator`」0.5pt 渐变描边，解决深色模式下卡片边缘发糊的问题。
- **舞台克制光晕**：`StageCard` 新增可选 `ambientTint: Color?`，在落定结果或倒计时运行/预警时于卡片顶部铺一层极淡径向光晕（浅色 5%、深色 9%）。
- **主按钮触感**：`PrimaryButton` 增加悬停微缩放（`1.018`）与 `.contentTransition(.symbolEffect(.replace))` 图标过渡。
- **统一进度条**：抽离 `ThinProgressBar(progress:tint:height:)`，供班级页、倒计时与选班大厅共用。

### 2. 课堂点名页（`Random/ClassroomViews.swift`）
- 舞台顶部与 `StageBadge` 并列展示公平加权徽标（仅在 `fairPick` 开启且已落定时显示），学生质疑抽中频率时大屏直接有据可查。
- 点名落定且可撤销时，主按钮旁平滑出现「请假重抽」胶囊按钮，一步完成「放回 + 补抽」。
- 数据统计栏底部增加 4pt 本轮抽取进度条，全班抽满自动切换绿色。

### 3. 侧边栏与选班大厅（`Random/RootView.swift`）
- 抽离 `SidebarRowButton`，为未选中侧边栏项补齐 macOS 原生悬停浅底高亮；年级组头右侧增加班数角标。
- `WelcomeView`（选班大厅）在宽屏下居中对齐（`maxWidth: 920`），顶部就绪舞台新增「继续 XX 班（已抽/总人数）」快捷胶囊，减少冷启动回班的点击步数。
- 抽离 `QuickToolTile`，与 `ClassTileCard` 统一悬停边框高亮与微抬升动效，`ClassTileCard` 改用 `ThinProgressBar`。

### 4. 随机工具、历史记录与设置（`ToolViews.swift` / `HistoryView.swift` / `SettingsView.swift`）
- **倒计时（`CountdownView`）**：舞台新增 6pt 实时递减进度条与 `.numericText(countsDown: true)` 数字滚落，按剩余时长自动切换色阶（正常强调色 / ≤30 秒橙色 / ≤10 秒红色）；主操作区新增「+30 秒」不中断课堂加时按钮，并将重置按钮统一为胶囊样式。
- **随机分组（`GroupingView`）**：各组卡片按 6 色系统色轮换色点与极淡底框，后排学生可快速定位自己所在组。
- **随机顺序（`SequenceView`）**：完整顺序网格高亮前 3 名；剪贴板复制统一改走 `Pasteboard.copy`。
- **历史记录（`HistoryView`）**：筛选栏内置「搜索姓名或结果」输入框，支持按姓名、工具名或班名即时过滤。
- **设置页（`SettingsView`）**：外层补齐 `.frame(maxWidth: .infinity)`，宽窗口下居中排版。
